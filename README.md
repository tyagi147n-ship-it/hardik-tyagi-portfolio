# Hardik Tyagi — Futuristic Portfolio

A responsive portfolio with a blue and purple visual theme, an interactive 3D-style particle globe, animated project panels, and responsive layouts.

## Run it

1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. To publish it, upload `index.html`, `style.css`, and `script.js` to GitHub Pages, Netlify, or another static web host.

The 3D-style globe is drawn with the browser canvas and needs no libraries or installation. Drag it or move your pointer across it to rotate the scene. Project cards also respond to pointer movement. Google Fonts load from the internet.

## Update your details

- Edit the text and project descriptions in `index.html`.
- Update your email, LinkedIn, or GitHub links in `index.html` if they change.
- Change colors and layout in `style.css`.

Project links currently point to your GitHub profile because individual repository URLs were not included in the resume.
